# Azua

Azua finds the weak spots in vibe-coded TypeScript/JavaScript apps and fixes them.

- **Diagnoser** – a fine-tuned model that tells professionally built code from AI-generated ("vibe-coded") code and ranks which files need attention first.
- **Rewriter** – small, targeted fixes, verified in a sandbox that replays the app before and after the change so its behavior stays the same.
- **GitHub App** – delivers those fixes as pull requests.

**Status:** early prototype (November 2026). The diagnoser is in development; the rewriter and GitHub App come next.
